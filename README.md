# discord-in-office

디스코드를 **투박한 Excel 화면으로 위장**해 주는 Electron 래퍼.
도서관·사무실처럼 화면이 노출되는 공간에서 디스코드를 쓸 때 눈치를 덜 보게 해 준다.

## 동작 방식

- 디스코드 웹(`discord.com/app`)을 Electron 창에 띄우고 CSS/JS를 주입한다.
- 주입 요소:
  - 상단 초록 **리본 바**(파일·홈·삽입… 탭) + **수식 막대** (`=SUMIF(C:C,"회의",H:H)`)
  - 하단 **시트 탭** (Sheet1 · 채팅로그 · Sheet3) + 상태 표시줄(시계)
  - 메시지 목록 왼쪽에 **행번호 세로줄**, 메시지마다 격자선
  - 서버 아이콘은 회색조로 눈에 덜 띄게 처리
  - 메시지를 클릭하면 수식 막대가 `="메시지 내용"` 처럼 반응 (셀 클릭 흉내)
  - 창 제목은 항상 `재고관리_2026.xlsx - Excel` 로 고정
  - 디스코드 다크 테마를 **강제로 라이트로 스왑** (`theme-dark` → `theme-light`).
    UI 리프레시로 변수 오버라이드가 무시돼도 테마 클래스 스왑은 항상 통한다.
- 이모지 가시/비가시 옵션:
  - **보기 → 이모지 숨기기 (⌘E)** 로 토글. 설정은 재시작 후에도 유지.
  - 비가시 모드에서는 이모지 이미지 대신 노란 셀 노트 스타일의 `[눈물웃음]`,
    `[엄지업]` 텍스트가 나온다. 커스텀 이모지는 `[:이모지이름:]`.
  - **스티커**는 디스코드가 내장 렌더하는 이름을 그대로 `[스티커:시오짱]`으로 표기.
    스티커 자리는 한 줄로 접혀 공간을 차지하지 않고, **라벨을 누르면 원본이
    펼쳐지고** 다시 누르면 접힌다.
  - **사진**(첨부·임베드 이미지)은 한 줄 높이로 접혀 `눌러서 사진보기` 버튼만 남는다.
    **버튼을 누르면 자리에서 펼쳐지고**, 펼친 사진을 다시 누르면 접힌다.
    캐러셀(1/4)은 묶음 단위로 함께 펼쳐진다.
  - **프로필 사진**은 이니셜 회색 셀로 마스크, 아바타 장식·역할 아이콘·클랜 배지는 숨김.
  - **길드 아이콘·길드 배너**도 숨김 모드에서 함께 제거.
  - **텍스트 이모지**(상태 메시지·채널명 등 유니코드 문자)도 같은 방식으로 설명 표기.

## 강제 라이트 테마의 원리

2025년 UI 리프레시 이후 디스코드는 테마 토큰을 CSS 파일에 직접 정의하고
선언 순서 때문에 `theme-darker`(Onyx)가 이긴다. 클래스 스왑만으로는 못 이기므로,
페이지 안에서 같은 오리진의 CSS 원문을 fetch해 `theme-light` 블록의 토큰
(약 600개)을 전수 추출한 뒤 `!important`로 재정의한다. 다크 클래스가 살아
있어도 값 자체가 라이트로 고정된다.

## 실행

```bash
npm install
npm start
```

첫 실행 시 디스코드 로그인(비밀번호 또는 QR)을 하면 된다.

Windows에서도 동일하게 동작한다. 숨김 토글 단축키만 `Ctrl+E`가 된다.
`DIO_DEBUG=1 npm start`로 실행하면 화면 캡처(`%TEMP%\dio-shots`)와
원격 스크립트 실행(`%TEMP%\dio-exec.js`) 디버그 루프가 켜진다.

## 조작

| 단축키 | 동작 |
| --- | --- |
| ⌘E | 이모지 가시/비가시 토글 |
| ⌘R | 새로고침 |

## 커스터마이징

- 파일명·수식 문구: `dio.js` 상단 `FILE_NAME`, `buildChrome()` 내부 문자열
- 리본 색: `excel.css`의 `#217346`(엑셀 그린)
- 이모지 설명 사전: `dio.js`의 `EMO` 객체 (없는 이모지는 `[원문]`으로 표기)

## 주의

- 디스코드 클라이언트 수정은 약관상 허용되지 않으므로, 계정 제재의 위험이 있다.
  부계정 사용을 권장한다. 디스코드 UI 구조가 바뀌면 일부 스타일이 깨질 수 있다
  (선택자는 `[class^=...]` 와일드카드 기반이라 어느 정도 버팀).
